# APINORDIC website

APINORDIC – Finnish honey from Southwest Finland (Varsinais-Suomi).

Static site (HTML, CSS, JS). Bilingual: Finnish / English via the FI/EN toggle (`data-fi` / `data-en` attributes).

## Pages
- `index.html` – home
- `hunajamme.html` – our honey
- `tarinamme.html` – our story
- `mehilaiset-luonto.html` – bees & nature
- `pesaosakkuus.html` – hive partnership (coming later)
- `verkkokauppa.html` – shop (coming later)
- `yhteystiedot.html` – contact
